# Standard Modules

The following standard modules are available:

1. [AIFF-hul](/modules/aiff/): Audio Interchange File Format
    - AIFF 1.3 \[[AIFF](/references#aiff)\]
    - AIFF-C \[[AIFF-C](/references#aiff-c)\]
2. [ASCII-hul](/modules/ascii/): ASCII-encoded text
    - ANSI X3.4-1986 \[[ANSI X3.4](/references#x3.4)\]
    - ECMA-6 \[[ECMA-6](/references#ecma-6)\]
    - ISO 646:1991 \[[ISO 646](/references#iso646)\]
3. [BYTESTREAM](/modules/bytestream/): Arbitrary bytestreams (always well-formed and valid)
4. [GIF-hul](/modules/gif/): Graphics Exchange Format (GIF)
    - GIF 87a \[[GIF87a](/references#gif87a)\]
    - GIF 89a \[[GIF89a](/references#gif89a)\]
5. [HTML-hul](/modules/html): Hypertext Markup Language (HTML)
    - HTML 3.2 \[[HTML 3.2](/references#html-3.2)\]
    - HTML 4.0 \[[HTML 4.0](/references#html-4.0)\]
    - HTML 4.01 \[[HTML 4.01](/references#html-4.01)\]
    - XHTML 1.0 and 1.1 \[[XHTML](/references#xhtml-1.0)\]
6. [JPEG-hul](/modules/jpeg/): Joint Photographic Experts Group (JPEG) raster images
    - JPEG (ISO/IEC 10918-1:1994) \[[JPEG](/references#jpeg-1)\]
    - JPEG File Interchange Format (JFIF) 1.2 \[[JFIF](/references#jfif)\]
    - Exif 2.0, 2.1 (JEIDA-49-1998), and 2.2 (JEITA CP-3451) \[[Exif 2.1](/references#exif2.1), [Exif 2.2](/references#exif)\]
    - Still Picture Interchange File Format (SPIFF, ISO/IEC 10918-3:1997) \[[SPIFF](/references#jpeg-3)\]
    - JPEG Tiled Image Pyramid (JTIP, ISO/IEC 10918-3:1997) \[[JTIP](/references#jpeg-3)\]
    - JPEG-LS (ISO/IEC 14495) \[[JPEG-LS](/references#jpeg-ls-1)\]
7. [JPEG2000-hul](/modules/jpeg2000/): JPEG 2000
    - JP2 profile (ISO/IEC 15444-1:2000 / ITU-T Rec. T.800 (2000)) \[[JP2](/references#jpeg2000-1), [ITU-T T.800](/references#itu-t.800)\]
    - JPX profile(ISO/IEC 15444-2:2004) \[[JPX](/references#jpeg2000-2)\]
8. [PDF-hul](/modules/pdf): Page Description Format (PDF)
    - PDF 1.0 through 1.6 \[[PDF](/references#pdf1.4)\]
    - Pre-press data exchange
        - PDF/X-1 (ISO 15930-1:2001) \[[PDF/X-1](/references#pdfx1)\]
        - PDF/X-1a (ISO 15930-4:2003) \[[PDF/X-1a](/references#pdfx1a)\]
        - PDF/X-2 (ISO 15390-5:2003) \[[PDF/X-2](/references#pdfx2)\]
        - PDF/X-3 (ISO 15930-6:2003) \[[PDF/X-3](/references#pdfx3)\]
    - Tagged PDF \[[PDF](/references#pdf1.4)\]
    - Linearized PDF \[[PDF](/references#pdf1.4)\]
    - PDF/A-1 (ISO/DIS 19005-1) \[[PDF/A](/references#pdfa)\]
9. [TIFF-hul](/modules/tiff/): Tagged Image File Format (TIFF) raster images
    - TIFF 4.0, 5.0, and 6.0 \[[TIFF 4.0](/references#tiff4), [TIFF 5.0](/references#tiff5), [TIFF 6.0](/references#tiff6)\]
    - Baseline 6.0 Class B, G, P, and R \[[TIFF 6.0](/references#tiff6)\]
    - Extension Class Y \[[TIFF 6.0](/references#tiff6)\]
    - TIFF/IT (ISO 12639:2003) \[[TIFF/IT](/references#tiffit)\]
        - File types CT, LW, HC, MP, BP, BL, and FP, and conformance levels P1 and P2
    - TIFF/EP (ISO 12234-2:2001) \[[TIFF/EP](/references#tiffep)\]
    - Exif 2.0, 2.1 (JEIDA-49-1998), and 2.2 (JEITA CP-3451) \[[Exif 2.1](/references#exif2.1), [Exif 2.2](/references#exif)\]
    - GeoTIFF 1.0 \[[GeoTIFF](/references#geotiff)\]
    - TIFF-FX (RFC 2301) \[[TIFF-FX](/references#tiff-fx)\]
        - Profiles C, F, J, L, M, and S
    - Class F (RFC 2306) \[[Class F](/references#classf), [RFC 2306](/references#rfc2306)\]
    - RFC 1314 \[[RFC 1314](/references#rfc1314)\]
    - DNG (Adobe Digital Negative) \[[DNG](/references#dng)\]
10. [UTF8-hul](/modules/utf8/): UTF-8 encoded text \[[Unicode](/references#unicode)\]
11. [WAVE-hul](/modules/wave/): Audio for Windows \[[WAVE](/references#wave), [WAVEFORMAT](/references#waveformat)\]
    - PCMWAVEFORMAT \[[PCMWAVEFORMAT](/references#pcmwaveformat)\]
    - WAVEFORMATEX \[[WAVEFORMATEX](/references#waveformatex)\]
    - WAVEFORMATEXTENSIBLE \[[WAVEFORMATEXTENSIBLE](/references#waveformatextensible)\]
    - Broadcast Wave Format (EBU TECH 3285) version 0, 1 and 2 \[[BWF](/references#bwf)\]
    - RF64 (EBU TECH 3306) \[[RF64](/references#rf64)\]
12. [XML-hul](/modules/xml/): Extensible Markup Language (XML)
    - XML 1.0 \[[XML](/references#xml)\]
